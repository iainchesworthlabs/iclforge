**The TrueHD encoder can apply an object downmix's gains in the lower substreams (`EncoderConfig::object_downmix_scaling = ObjectDownmixScaling::kBedSubstreams`), which leaves the rows substream 3 codes as the objects themselves.** The default, `kChain`, writes the stream as before. In the new mode each bed row is coded with its pivot object at 1 and a matrix in each lower substream makes the downmix row; pan-law downmixes, single rows of unequal gains, quiet rows and rows that are combinations of other rows all build, and the realised gains are within half a 2^-14 step of the ones asked for. A bed row is still coded hotter than it is presented by 1 over its largest gain, a coefficient of 2 or more in a lower substream's matrix is refused, and the only outside decoder that has read these streams is FFmpeg, which decodes the 7.1, 5.1 and stereo presentations bit-exact with this library but does not decode substream 3.
