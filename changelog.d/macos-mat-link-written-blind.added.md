**The macOS audio backend now tries TrueHD (MAT): it looks for eight channels of 16-bit linear PCM at 192 kHz (176.4 kHz) among an output's physical formats and writes the bursts into it.** Core Audio has no format ID for MAT and Apple documents no path for it, so this is the one way left, the shape the other backends open, and it was written without a Mac. A device that offers the shape now reports `supports_mat_passthrough`, which means only that; the Hearth status list keeps macOS as not run until a receiver names the stream TrueHD. If a receiver reads the link as PCM the burst plays as loud noise, so a first try wants the volume at its lowest. The macOS CI leg compiles it and tests the format matching; the hosted Mac has no HDMI output, so no link is opened there.
