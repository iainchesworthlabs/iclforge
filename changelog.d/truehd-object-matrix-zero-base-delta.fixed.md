**A present coefficient of base 0 in an object matrix (restart sync 0x31EC) keeps its extension delta; added: `hb_substream3_object_extension` and a Python reference that applies the deltas.** The decoder dropped a coefficient whose base was 0 when the matrix was set up, and its finer part with it (a refinement from nothing); it is kept when the delta is not 0. The new hand-built stream holds the extension of the object matrix section (coefficient = base + delta / 2^(width + 1); new headers with widths, inherited widths, A = 0 with the deltas standing, a matrix of width 0, bases of 0 with deltas), decoded sample for sample by the C++ decoder and by `tools/references/truehd_syntax.py`, which now applies the deltas and reads A = 0 and B = 0 as the decoder does. Provisional against outside decoders (ERRATA 69, `libs/truehd/SUBSTREAM3.md`).
