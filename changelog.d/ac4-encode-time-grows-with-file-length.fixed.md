**`forge ac4-encode` no longer takes time that grows with the square of the file's length.** The encoder moved everything it still held of the input after every frame, and the command gives it the whole file at once, so doubling a file more than doubled the time. A 100 second 5.1 file at 256 kbit/s now takes 9.6 s where it took 23.3 s, and 25 seconds take 2.5 s where they took 3.4 s (median of five runs on a Ryzen 9 5950X); the stream is byte for byte the same.
