**`forge probe detail=matrix` lists every matrix section and `output_shift` of a TrueHD stream.** It decodes the stream and prints, for all four substreams and with no cap, each block header that sends matrices or output shifts: where it is (unit, substream, block, sample, restart), the shift of each matrix channel with the output channel it goes to, and each matrix's `out`, `frac_bits`, `f_shift`, `lsb_bypass`, `noise_shift`, reserved fields, coefficients as sent and the object audio extension's slopes. A per-substream summary says how many there are, so a substream that sends none reads as none rather than cut off. `json=1` adds a `matrix` member. The default `probe` output is unchanged. Tests run it on an encoded stream, on hand-built streams (including one with a non-zero `output_shift`) and on an object-audio stream.
