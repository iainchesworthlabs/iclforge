**`forge-gui` encodes TrueHD, and saves it in a project.** A button of the Open stream dialog opens **Encode TrueHD…**, which codes a WAV as a bare `.thd` (the same encode as `forge truehd-encode`, with verify, progress, Stop and the command line it is the twin of); it is a dialog of its own, not a fourth entry of the encoder workbench's codec list. A TrueHD session is saved as a project of codec `truehd` and opens back into the dialog. Containers and the metadata and rate options are the command line's.
