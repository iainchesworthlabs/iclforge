**TrueHD Atmos is written at 96 and 192 kHz, provisionally.** `forge truehd-atmos` and `EncoderConfig::object_channels` accept 96 000 and 192 000 Hz beside 48 000 Hz (the bed stays 7.1, so 8 channels at 192 kHz). The object matrices' ramp step now comes from one function, `object_ramp_step` (6552, 3276, 1636), used by the encoder and the decoder, the metadata frame stays 1536 samples, and the command passes the real access-unit length (80 and 160 samples) when it places the evolution frames. Our strict decoder reads the streams back bit for bit; the Dolby Reference Player plays the bed of a stream without evolution frames at both rates, and has not yet read the object metadata there (an unsigned evolution frame fails its check at every rate). The ramp step above 48 kHz, the rate model, the metadata frame length and the width of the scaled fine sum are the rule's reading, set out in `libs/truehd/notes/feature-truehd-atmos-96-192.md`.
