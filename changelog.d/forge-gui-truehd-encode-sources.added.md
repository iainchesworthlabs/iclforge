**The Forge window's Encode TrueHD dialog takes several WAV files.** "Several sources…" adds more WAVs after the first (`src=` on the command line), a map saying where each channel of each source goes in TrueHD's channel names (`map=0.0:L,0.1:R,1.0:C`), and a start offset in seconds for each source (`offset=1:0.25`). A map or an offset the command line would refuse is refused under its field, more than one source without a map is refused, and the command line at the bottom of the dialog carries all three. The sources are joined by the code `forge truehd-encode` runs (`core::parse_map`, `assemble` and `pad_leading`); the summary says which source channel went to which place.
