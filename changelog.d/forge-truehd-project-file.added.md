**A Forge project of codec `truehd` carries the whole Encode TrueHD dialog, in the window and in `forge project`.** `encode.truehd` holds `verify`, `downmix` and the options of "More options" (`restart`, `peakRate`, `rateCheck`, `bitrate`, `majorSync`, `firOrder`, `matrix`, `stereoMode`, `downmixGains`, each as the text the command line takes), `sources` holds the further WAV files with an `offsetSeconds` each, and `assignments` holds the `map=` rows. `forge project p.forgeproj out print` prints the `forge truehd-encode ... src= map= offset= truehd-...=` line the dialog shows and runs to the same bytes; a value `truehd-encode` would refuse is refused with its sentence before anything runs. The window saves all of it and opens it back into the dialog. A project that holds several WAV files no longer drops all but the first on opening.
