**The Forge window's Encode TrueHD dialog takes the encoder's options.** "More options…" opens fields for what `forge truehd-encode` reads as `truehd-restart=`, `truehd-major-sync=`, `truehd-peak-rate=`, `truehd-bitrate=`, `truehd-fir-order=`, `truehd-downmix-gains=`, `truehd-rate-check=`, `truehd-matrix=` and `truehd-stereo-mode=`. A field left empty is the encoder's own choice; a value the command line would refuse is refused under the field with the same sentence, and the Encode button waits. The command line at the bottom of the dialog carries them. The values, their limits and the encoder settings they make are one piece of code (`apps/shared/media/src/truehd_encode_core.{hpp,cpp}`) that the command line's encode now applies too, so the two cannot drift.
