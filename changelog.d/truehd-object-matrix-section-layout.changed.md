**The matrices of a TrueHD Atmos object substream (restart sync 0x31EC) are read and written in the object-audio layout of TH spec v3.20 §10.2.1a.** Every header first, then the coefficients, a presence mask and an `f_shift` for coefficients past 2. It reads the owner's disc and DEE's encodes to the bit; whether those streams then decode with every lossless check passing is the owner's next run (ERRATA 69). The hand-built substream 3 streams are regenerated.
