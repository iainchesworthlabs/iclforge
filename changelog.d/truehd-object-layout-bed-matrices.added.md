**`EncoderConfig::object_layout = ObjectLayout::kBedMatrices` writes the object substream the way the owner's streams have it (provisional; ERRATA 70).** Substream 3 has `min_chan` 8 and codes only the channels from 8 up; primitive matrices (a sign flip, matrix noise from `object_noise_shift`, optionally one LSB bypass matrix, and one mixing matrix for each object above the bed) rebuild all 9 to 16 object channels from the bed rows of substreams 0 to 2. The 7.1 bed is a fixed render of the objects, so `encode()` takes the objects alone; the encoder runs the matrices backwards in integers, noise and bypass included, and checks the result against the decoder's arithmetic. Held by `test_encoder_object_bed.cpp` and `tools/checks/verify_truehd_object_bed.py` (the Python reference decodes the streams of `iclforge-truehd-encode-tool object-bed=1`). Static within a restart interval; `forge truehd-atmos` still writes the independent layout.
