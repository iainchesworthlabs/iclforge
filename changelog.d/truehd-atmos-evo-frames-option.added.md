**`forge truehd-atmos truehd-evo-frames=all|every:N|first|none` chooses which of the metadata frames get an evolution frame.** The default (all) is as before. A licensed decoder reads the evolution frames of a stream that has the Atmos flag and reports "Consecutive Evo frames fail security check" when the tag of two frames in a row is wrong; the stream carries no tag, so the option lets a writer send fewer frames.
