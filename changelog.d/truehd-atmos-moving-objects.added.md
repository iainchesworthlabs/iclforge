**The TrueHD encoder can write moving objects in the object substream.** With `ObjectLayout::kBedMatrices` the matrices that mix the objects into the 7.1 bed now follow per-object paths (`EncoderConfig::object_paths`, in integer gains), so the matrix sections of substream 3 change from block to block: new coefficients, new headers when a bed row's matrix comes or goes (up to the 16 matrices of the section), and 1 to 3 LSB bypass bits. With `object_extension` set to slopes a moving object is one section and then plain blocks: the coefficients slide on the extension's slopes and a new section is sent only where the path turns or a coefficient has drifted. Without paths the stream is byte for byte what it was. The lossless check passes on every interval, and the Python reference writer plans the same sections from the same integers.
