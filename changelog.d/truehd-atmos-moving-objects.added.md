**The TrueHD encoder can write moving objects in the object substream.** With `ObjectLayout::kBedMatrices` the matrices that mix the objects into the 7.1 bed now follow per-object paths (`EncoderConfig::object_paths`, in integer gains), so the matrix sections of substream 3 change from block to block: new coefficients, new headers when a bed row's matrix comes or goes (up to the 16 matrices of the section), and 1 to 3 LSB bypass bits. An optional extension (`object_ramp`) ramps each coefficient across the block; it is provisional, read from one controlled encode, and decodes only under the decoder's lab settings for it. Without paths the stream is byte for byte what it was. The lossless check passes on every interval, and the Python reference writer plans the same sections from the same integers.
