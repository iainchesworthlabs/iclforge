**The Forge window's Open stream player plays a TrueHD track inside Matroska, MP4 and a Blu-ray transport stream.** A `.mkv`, `.mp4` or `.m2ts` with TrueHD was refused with "is not a valid AC-3 stream" while a bare `.thd` opened. The player now finds the first TrueHD track (the first one, as `forge decode` takes it), reads it where it lies in the file a window at a time (a transport stream is read whole), applies an MP4 edit list's priming and end, and plays, seeks and exports it as it does a bare stream; the summary line names the container. The picker has a "TrueHD in a container" filter. AC-3, E-AC-3 and AC-4 in a container are unchanged: the player still refuses them (QC reads them).
