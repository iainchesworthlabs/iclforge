**The Forge window's Encode TrueHD dialog takes the channel meaning.** "Channel meaning…" opens a table of what the stream says about each presentation: the dialogue norm, mix level, source format and control bit of the 2, 6 and 8 channel presentations and the two DRC start-up gains, the options `forge truehd-encode` reads as `truehd-dialnorm-6ch=`, `truehd-mix-level-8ch=`, `truehd-control-2ch=`, `truehd-drc-start-up-gain=` and the rest. A field left empty is written as zero; a value the command line would refuse is refused under the field with the same sentence, and the Encode button waits. The command line at the bottom of the dialog carries them, and the summary says the meaning was written and that it is provisional (no oracle until the DEE set, `libs/truehd/ERRATA.md` questions 51 to 55). What each option takes and how it fills the encoder's configuration moved into `apps/shared/media/src/truehd_encode_core.{hpp,cpp}`, which `forge truehd-encode` now uses as well, so the two cannot drift; the command line's sentences are unchanged.
