**`truehd::Decoder::reset()` clears the decoder where it stands.** It used to build a new decoder state before releasing the old one, so a restart (a seek, a format change) needed the decoder's 158 KB twice and ran out of memory on an ESP32-C6 with `std::bad_alloc`. It now allocates nothing, cannot fail and is `noexcept`; the samples the next stream decodes to are the same, in the same buffers.
