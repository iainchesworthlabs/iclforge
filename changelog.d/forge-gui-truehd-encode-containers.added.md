**The Forge window's Encode TrueHD dialog writes Matroska, MP4 and a Blu-ray transport stream.** The name chosen under Save as decides: `.thd` is the bare stream as before, `.mkv` (or `.mka`, `.webm`), `.mp4` (or `.m4a`, `.mov`) and `.m2ts` (or `.ts`) hold the same access units in that container, written by the code `forge truehd-encode in.wav out.mkv`, `mkv`, `mp4` and `ts` use. The summary names the container, the command line at the bottom of the dialog is the one that does the same, and any other name still gets `.thd` added. The wrapping moved from the command line's own sources to `apps/shared/media/src/truehd_wrap.{hpp,cpp}` so that both programs share it; the commands print what they did before.
